# ALXPRGS Notify

Один владелец, два репозитория. Сервер/API/MCP/веб/SDK/skill здесь; Kotlin-клиент в `../notifications-app`. Сначала прочитай README и docs/ACCEPTANCE.md; для продолжения — docs/HARNESS_PLAN.md.

- Сохраняй чужие изменения. Не меняй SSO или production в рамках разработки Notify.
- Не добавляй скрытый вход, тестовые токены или обходы SSO/биометрии в работающий сервер. Синтетические учётные данные допустимы только в изолированных тестовых БД.
- Окончательный ответ и outbox фиксируются одной транзакцией. Повторы доставки допустимы; двойное решение — нет. Не трактуй pending/отказ/истечение как согласие.
- Не печатай токены, SSO callback query, приватные ключи и тела чувствительных запросов. Не коммить .env, Firebase credentials, реальные БД и ключи подписи APK.
- Новую функцию включай в capabilities только после сквозной реализации. Будущие endpoints не документируй как существующие.
- Проверяй затронутые контракты на настоящей SQLite; SDK — после установки wheel. Разделяй локальные, имитационные и реальные внешние проверки.
- Не создавай агентов или отдельные чаты без поручения владельца. Не публикуй пакеты, не делай push/deploy автоматически.
